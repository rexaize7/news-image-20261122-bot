A dark world-map briefing board that sums up **Sunday, 22 November 2026** in
one 1024 × 1024 image: seven red pins on a stylised world map, each matching a
numbered story card with a headline and a full caption — COP31 ends with no
fossil-fuel deal (Antalya), a drone smashes a flat block in Dymer, Ukraine, a
sea drone hits a Russian warship at Benghazi, Iran hits a Bahrain site and
tankers are struck near Hormuz, the Cikande candy-factory fire in Indonesia,
the Democrats' biggest US House majority since 1992, and the World Court's
Rohingya genocide ruling — plus a yellow ticker with six more stories
(Mexico, markets, EU–Indonesia trade, BepiColombo, Nigeria, MotoGP) and a
closing card, “Why this day mattered”. `main.py` (Python 3, standard library
only, no network) copies the pre-drawn `entry.png` to `/output/entry.png`,
byte for byte on every run.

## Run it

```sh
python3 main.py
```
